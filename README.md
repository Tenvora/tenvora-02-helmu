# حُلم — Helmu (نموذج تسويقي)

نموذج صفحة تسويقية عربية (RTL) من سلسلة معارض **Tenvora** — الرقم `02-helmu`.

## ما هذا الموقع؟
صفحة هبوط لصفحة واحدة لاستوديو تصميم داخلي فاخر متخصص بفلل دبي ومساحات
الضيافة والمساحات التجارية، تحاكي النطاق **helmu.ae** (نطاق تجريبي — لا خلف
خادم ولا إرسال بيانات؛ نموذج الحجز يُعترض محليًا بالكامل).

- **الغرض:** معرض مشاريع + منهجية من أربع خطوات تدفع مالك الفيلا لحجز جلسة استشارية.
- **النطاق المحاكى:** `helmu.ae` — دبي، الإمارات.
- **النص:** عربي فصيح حديث بنبرة خليجية راقية، بلا نصوص وهمية.

## المدرسة التصميمية: N3 — Glassmorphism Aurora
- قاعدة بيضاء دافئة `#F6F3EE` تتدرج إلى شفق الليلك/الخوخ.
- بطاقات زجاجية مصنفرة (`backdrop-filter: blur`) مع تدهور صلب عبر `@supports not`.
- شبكة شفق متحركة (4 حقول لونية ضبابية) في CSS خالص بحركة بطيئة 24–38 ثانية.
- رفع البطاقات وتكثيف الضبابية عند التحويم، وظلال طويلة مبعثرة.
- خطوط: `Cairo` (نصوص) + `Alexandria` (عناوين) من Google Fonts.
- كشف عند التمرير عبر AOS مع ضمان بقاء كل المحتوى ظاهرًا إذا فشل تحميله.

## البنية
`index.html` + `assets/styles.css` + `assets/app.js` — ملفات ثابتة خالصة،
تُفتح مباشرة من القرص بلا أي خطوة بناء. كل الرسوم الداخلية SVG مضمّن، وكل
دوائر المواد مرسومة بالتدرجات اللونية في CSS.
